PUBLICAR EN GITHUB PAGES
1. Suba index.html, archivos.js y palabras.js a la carpeta publicada.
2. Suba sus archivos HTML, LSP, DWG, PDF y otros formatos al MISMO directorio.
3. Abra el sitio PUBLICADO (usuario.github.io/repositorio/), no la vista github.com.
4. Escriba una letra o parte del nombre; por ejemplo, "texto" encontrará
   "organzador_texto.html". Los resultados aparecen mientras escribe.
5. Seleccione con clic o flechas Arriba/Abajo y Enter.
6. Los HTML se abren en una pestaña nueva. Los demás archivos solicitan
   confirmar la descarga (Sí o No).
7. Los archivos de control index, LEAME, actualizar, archivos y palabras
   no se muestran entre los resultados.

BÚSQUEDA EN GITHUB
- En direcciones usuario.github.io se identifica automáticamente el repositorio.
- Se utiliza la API pública de GitHub para obtener todos los nombres de archivos.
- Solo busca archivos del MISMO directorio, no de subcarpetas.
- No necesita mantener manualmente una lista de archivos en GitHub Pages.
- Para sitios con dominio personalizado, edite CONFIG_GITHUB en index.html
  e indique usuario y repositorio. Opcionalmente carpeta y rama.
- Si publicó mediante GitHub Actions con rama/carpeta no convencional,
  puede definir también CONFIG_GITHUB.rama y CONFIG_GITHUB.carpeta.
- La API pública tiene límites de consultas sin autenticación. Si se alcanza
  el límite o no hay conexión, el catálogo local archivos.js sirve de respaldo.
- Un archivo recién publicado puede tardar en aparecer en GitHub Pages.

USO EN WINDOWS, SIN LOCALHOST
1. Ponga index.html, archivos.js, palabras.js y sus utilidades en una carpeta.
2. Ejecute actualizar_archivos.bat al añadir o quitar archivos.
3. Abra index.html con doble clic. El .bat actualiza archivos.js para uso local.
