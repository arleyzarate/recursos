PUBLICAR EN GITHUB PAGES (sin localhost)
1. En la carpeta publicada por GitHub Pages, coloque index.html y palabras.js.
2. Coloque los archivos de sus utilidades HTML en la MISMA carpeta que index.html.
3. Abra la DIRECCION PUBLICADA DE GITHUB PAGES, no el enlace a la vista del archivo en github.com.
   La dirección publicada suele tener esta forma: https://usuario.github.io/repositorio/
4. Escriba el nombre exacto de un archivo HTML con o sin la extensión y pulse Enter.
   Ejemplo: organzador_texto o organzador_texto.html
5. Si el archivo existe, se abre en otra pestaña y aparece "Comando correcto".
   Si no existe, aparece "Error de comando".
6. No es necesario modificar archivos.js ni ejecutar actualizar_archivos.bat en GitHub Pages.

IMPORTANTE PARA GITHUB PAGES
- Los nombres de los archivos y sus mayúsculas/minúsculas deben coincidir exactamente.
- El index.html y las utilidades deben estar en la carpeta que publica GitHub Pages.
- Asegúrese de que la publicación corresponda a la versión más reciente del repositorio.
- GitHub Pages debe estar activado en Settings > Pages del repositorio.
- La comprobación se hace en línea usando una petición HEAD (con GET de respaldo).

USAR EN WINDOWS SIN SERVIDOR, SIN LOCALHOST
1. Extraiga todos los archivos del ZIP a la misma carpeta.
2. Copie sus archivos HTML junto a index.html.
3. Ejecute actualizar_archivos.bat cada vez que cambie los archivos HTML.
   Este paso crea el catálogo archivos.js, requerido al abrir páginas con file://.
4. Abra index.html con doble clic y escriba el nombre del archivo.
5. La pagina abre la utilidad en una nueva pestaña.
